# Alice app icon v2

Candidate icon concept for review. The companion PNG uses an integrated **A + conversation bubble + voice waveform** symbol in Alice's cyan, blue, and violet palette.

The current production icon files have not been replaced.

`app-icon-v3-scifi.png` is a more futuristic refinement with nano-ceramic depth, cyan energy channels, and restrained violet illumination. It preserves the same A/chat/voice identity.

`app-icon-v4-amber-scifi.png` replaces the common blue-purple AI palette with graphite, warm ceramic white, amber-orange energy, and small phosphor-lime accents.

`app-icon-v5-calm.png` is the restrained version: matte charcoal, warm off-white, muted orange, and olive with no neon glow or metallic detailing.
